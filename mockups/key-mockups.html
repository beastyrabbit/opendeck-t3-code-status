T3 Code status keys — five visual concepts

Mockups for the OpenDeck / Stream Deck plugin. Every key is a 144×144 viewBox SVG built from rect, circle, path, line, polygon and text only, with the fonts DejaVu Sans / sans-serif, so any key below can be pasted into src/render.ts unchanged. Each concept is shown at 2× for inspection and at true physical size (76 CSS px ≈ 2 cm at 96 dpi). Judge the 1× rows from arm's length at 100 % browser zoom; that is what the user sees.

Design rules applied throughout: one primary glyph or numeral per key, at most one secondary element; primary numerals ≥ 56 units tall (most are 63–79); no text below 22 units; every status colour is paired with a distinct shape; "needs you" states blink (frame A / frame B shown side by side, plus a live key).

Shared vocabulary (used by all five concepts)

Combined-key priority everywhere: needs you › failed › usage limit › working › open-but-idle › nothing open. Connection states replace the content of every key type; pressing a key only retries the connection, so no key promises an action it cannot take.
